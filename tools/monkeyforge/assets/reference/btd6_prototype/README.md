# Local prototype references

The downloaded BTD6 archives in this directory are local prototype references supplied by the
project owner. The archives contain static OBJ/DAE meshes and texture atlases but no usable
animation skeletons, source licenses, or redistribution grants.

Do not commit or redistribute the extracted models. Before publishing MonkeyForge, replace them with
an original model or a substantially redesigned asset whose provenance and license are documented.

Dart Monkey is the initial proportion reference because it exposes the neutral body, eyelids, and
held dart as separate objects. The original MonkeyForge bases are generated procedurally instead;
these files should not enter the public repository, training set, or released game.
