# Canonical monkey asset

Place the rigged base at `assets/base/monkey_base.glb`. Keep source `.blend` files in your team's
large-file storage if they become too large for the repository.

Required socket node names are listed in the root README. The body should face Blender `-Y`, use
`+Z` as up inside Blender, apply transforms before export, and export to GLB for the engine-facing
bundle.
