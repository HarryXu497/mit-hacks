# First screen visual specification

- Primary viewport: 16:10 laptop display.
- Focal surface: portrait green magnetic tactics board in a restrained silver
  frame, with the toolbar mounted to the lower frame.
- Players: red `1–5`, yellow `6–10`; one black-and-white ball.
- App chrome: deep charcoal, hairline blue-gray borders, humanist sans-serif.
- Accents: coral-red recording state, electric blue selected tool, natural
  yellow/red magnetic tokens, white marker strokes.
- Layout: quiet top bar, centered board, narrow right transcript/result rail,
  and a slim full-width timeline.
- Allowed main copy: “Tactic Lab”, “Build-up pattern”, “Start recording”, “Stop
  recording”, “Resume”, “Reset”, “Live transcript”, “Listening…”, “Generate
  JSON”, and “Session timeline”.
- Containers remain open and functional; avoid dashboard card grids, glow,
  stadium imagery, decorative metrics, opponent trays, and roster controls.
